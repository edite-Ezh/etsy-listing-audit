# Meistarklases demonstrācijas plūsma

## Pirms demonstrācijas

1. Pārbaudi, ka ChatGPT desktop lietotne un Chrome paplašinājums ir atjaunināti.
2. Chrome atver Etsy sludinājumu un pārliecinies, ka EverBee panelis strādā.
3. Pārbaudi piegādes adreses: USA 10005, UK W13 9LS un Germany.
4. Atver tukšu testa Google Sheet tikai tad, ja demonstrēsi atslēgvārdu eksportu.
5. Atver jaunu Codex sarunu, lai skill būtu svaigi ielādēts.

## Live demonstrācija

1. Parādi Etsy sludinājumu, neizskaidrojot savu secinājumu iepriekš.
2. Codex raksti:

```text
Izmanto $etsy-listing-audit un izanalizē Etsy sludinājumu manā atvērtajā Chrome cilnē.
```

3. Kamēr notiek audits, paskaidro atšķirību starp hero signālu un apraksta tekstu.
4. Rezultātā izcel:
   - primāro buyer intent;
   - vienu būtisku signālu konfliktu;
   - vienu trūkstošu infografiku;
   - cenas un piegādes attiecību;
   - hero ideju, ko var izdalīt.
5. Parādi, ka skill beigās jautā par atslēgvārdu sarakstu.

## Rezerves plāns

Ja Chrome vai EverBee savienojums nestrādā, izmanto iepriekš sagatavotus ekrānuzņēmumus un `FALLBACK-PROMPT-LV.txt`. Demonstrācijas mērķis ir metodoloģija, nevis pārlūka tehniska atkļūdošana.
