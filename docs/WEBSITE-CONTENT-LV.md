# Etsy Listing Audit meistarklases materiāli

Izmanto mākslīgo intelektu, lai strukturēti analizētu Etsy sludinājuma buyer intent, hero attēlu, galeriju, materiālus, SEO tagus, cenu un piegādi.

## Izvēlies savu variantu

### A. Es lietošu Codex

Lejupielādē:

- **Codex uzstādīšanas instrukciju** — soli pa solim par lietotni, Chrome, EverBee un Google Sheets.
- **Etsy Listing Audit skill ZIP** — lokālai instalācijai un meistarklases darbam.
- **Etsy Listing Audit plugin ZIP** — pilna izplatīšanas pakotne.

Pēc instalācijas atver Etsy sludinājumu Chrome un raksti:

```text
Izmanto $etsy-listing-audit un izanalizē Etsy sludinājumu manā atvērtajā Chrome cilnē.
```

### B. Es lietošu ChatGPT bez skill

Lejupielādē **garo Etsy Listing Audit promptu**, ielīmē to ChatGPT sarunā un pievieno Etsy sludinājuma saiti.

Ja ChatGPT nevar nolasīt visus Etsy vai EverBee datus, pievieno ekrānuzņēmumus ar:

- hero un galeriju;
- variantiem un personalizāciju;
- EverBee tagu tabulu;
- favorītiem un listing date;
- piegādes cenu un termiņu.

## Svarīgi

- Katrs sludinājums tiek analizēts atsevišķi.
- EverBee dati ir aplēses.
- Audits automātiski nepārraksta tavu sludinājumu.
- Vispirms pārskati secinājumus; tikai tad veic izmaiņas Etsy.
